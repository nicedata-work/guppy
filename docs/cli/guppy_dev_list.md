# guppy dev list

## Synopsis

List the locally developed templates the install ledger knows about —
records whose source is a directory (added with "guppy template add
<dir>"). Developed templates live where you author them; guppy only
remembers where.

## Usage

```
guppy dev list
```

## Global flags

| Flag | Description |
|------|-------------|
| --config | path to guppy.toml settings file |
| --directory | run as if started in this directory |
| --interactive | enable interactive prompts |
| --offline | disable all network access |
| -q, --quiet | only print errors |
| -v, --verbose | increase output verbosity |
