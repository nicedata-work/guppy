# guppy template clone

## Synopsis

Copy a template out to a local directory for editing

## Usage

```
guppy template clone <id> [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| --into | destination directory (default: ./<id>) |


## Global flags

| Flag | Description |
|------|-------------|
| --color (default auto) | color output: auto, always, never |
| --config | path to guppy.toml settings file |
| --directory | run as if started in this directory |
| --interactive | enable interactive prompts |
| --no-progress | disable progress output |
| --offline | disable all network access |
| -q, --quiet | only print errors |
| -v, --verbose | increase output verbosity |
