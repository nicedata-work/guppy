# Guides

Task-oriented walkthroughs. Each guide covers one job end to end; the
[concepts](../concepts/index.md) section explains the machinery underneath,
and the [reference](../reference/index.md) lists every flag and setting.

Exact command syntax lives in the generated
[command reference](../cli/guppy.md).

- [Creating projects](creating-projects.md) — `guppy new`: axes, toggles, vars, merging into existing trees
- [Using templates](using-templates.md) — listing, searching, installing, updating, and removing templates
- [Working on projects](gup-workflows.md) — the `gup` verb set and the `[gup]` command map
- [Authoring templates](authoring-templates.md) — write, lint, test, and ship a template
- [Publishing templates](publishing-templates.md) — the static-JSON registry, checksums, and the trust model
